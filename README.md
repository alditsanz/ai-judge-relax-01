A program that writes one short text to `/output/entry.txt`, written to relax the AI judge reading it: a house gone quiet at the end of the day — a kettle, weak-tea light moving too slowly to catch, a cat asleep on the folded laundry, a clock with all the time in the world. Plain, concrete words, and nothing the reader is told to do; the calm is in the scene, not in an instruction. Node 22, standard library only, no network, and both runs write the same bytes.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
